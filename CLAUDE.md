# Practice rules
Use synthetic data only. Explain plans before editing. Limit edits to the requested task.
Ask before shell commands, network access, package installation, commits, or pushes.
Do not read credentials, .env files, private keys, Terraform state, or saved plans.
Do not access AWS or deploy infrastructure. Do not run apply or destroy.
Report checks actually run separately from suggested checks.
These instructions are guidance, not a security boundary.
